# 🎉 Luxury Birthday Website Template

A modern, dynamic, and interactive single-page birthday celebration website built with Tailwind CSS, Lucide Icons, and Canvas Confetti. Designed to be easily customized and sold as a digital service.

## ✨ Features

- **Luxury Theme**: Pastel Pink & Gold aesthetic with floating background animations (balloons, glowing orbs, celestial sparkles).
- **Hero Countdown Timer**: Real-time countdown to the birthday milestone.
- **Party Confetti Cannons**: Full-screen interactive celebration confetti via `canvas-confetti`.
- **Photo Moments Gallery**: Responsive grid with hover effects and full-screen lightbox modal.
- **3D Mystery Memory Cards**: Interactive flip cards with heartfelt messages and inside jokes.
- **Interactive Birthday Cake**: SVG tier cake with 5 flickering candles that can be blown out with realistic smoke animations and celebration popup modal.
- **Virtual Guestbook**: Real-time wishes wall stored in browser `localStorage` with heart like counters.
- **Built-in Music/Chime Synthesizer**: Web Audio API melody player.
- **2-Minute Customization**: Clean `BIRTHDAY_CONFIG` object in `<script>` for quick customization.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or deploy directly to GitHub Pages, Vercel, or Netlify.
